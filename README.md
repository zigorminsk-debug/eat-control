# Еда и самочувствие — Android

Нативное Android-приложение на Java для локального дневника питания и желудочно-кишечных симптомов.
Интерфейс на русском языке, без сторонних библиотек.

Приложение: `by.arena.fooddiary` · версия 1.1.0 (versionCode 3)

## Что умеет приложение

- записывать приёмы пищи: дата и время, тип приёма, продукты/напитки, порция, комментарий;
- записывать вздутие, газы, боль, стул и уровень стресса по шкале 0–10;
- сохранять контрольные отметки в периоды без выраженных симптомов;
- показывать историю и краткую сводку за последние 14 дней;
- находить повторные совпадения: какие продукты были в записях о еде в течение 12 часов до заметного вздутия (4/10 и выше), и отдельно показывать совпадения с контрольными отметками;
- экспортировать записи в CSV и удалять одну запись или весь дневник;
- **раздел «Помощь»** со справочной страницей «Газы и вздутие: причины, обследование и лечение» — вшита в приложение и работает без интернета;
- **автообновление**: приложение само проверяет новые версии на GitHub, предлагает обновление и ставит APK поверх установленной версии.


## Постоянный ключ подписи

Релизная сборка подписывается **постоянным** ключом из `keystore/release.keystore`
(алиас `food-diary`, RSA 4096, самоподписанный сертификат, действует до 2056 года).
Из-за этого новая версия ставится **поверх** ранее установленной: Android требует,
чтобы подпись совпадала с подписью уже установленного пакета, иначе он предложил бы
сначала удалить старое приложение (и записи дневника были бы потеряны).

Параметры ключа лежат в `keystore.properties`:

| Параметр | Значение |
|---|---|
| `storeFile` | `keystore/release.keystore` |
| `storePassword` / `keyPassword` | `fooddiary-release-2026` |
| `keyAlias` | `food-diary` |
| SHA-256 сертификата | `09:F2:08:8D:...:29:74:06` |

Сборка использует схемы подписи **v1 + v2 + v3**: v1 нужен старым устройствам
(API 23+), v2 обязателен для Android 11+, v3 — для обновлений поверх.

> Ключ и пароли лежат в репозитории, чтобы GitHub Actions всегда подписывал
> приложение тем же ключом. Для публичного репозитория перенесите ключ в
> GitHub Secrets (`KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)
> — workflow подхватит их автоматически.

## Приватность

Записи дневника хранятся в приватном локальном хранилище приложения и **никуда не
отправляются**. Приложение запрашивает `INTERNET` только ради автообновления: по сети
уходят запрос манифеста версии и файл APK. Резервное копирование приложения отключено.
Удаление приложения удаляет локальный дневник — при необходимости заранее экспортируйте CSV.

## Сборка

Требуется JDK 17, Android SDK Platform 35, Android Build Tools 35.0.0 и Gradle 8.7.

```bash
./gradlew assembleDebug    # отладочная сборка, пакет by.arena.fooddiary.debug
./gradlew assembleRelease  # релизная сборка, пакет by.arena.fooddiary
```

Готовый APK: `app/build/outputs/apk/release/food-diary-1.1.0.apk`

## Автосборка и автообновление (GitHub Actions)

| Workflow | Когда запускается | Что делает |
|---|---|---|
| `.github/workflows/build.yml` | push в `main`/`arena/**`, pull request, ручной запуск | собирает release и debug APK, проверяет подпись постоянным ключом, сохраняет артефакты |
| `.github/workflows/release.yml` | тег `v*` или ручной запуск с версией | собирает подписанный APK, публикует релиз на GitHub и файл `update.json` |

`update.json` — манифест, который читает приложение:

```json
{
  "version_code": 3,
  "version_name": "1.1.0",
  "url": "https://github.com/zigorminsk-debug/eat-control/releases/download/v1.1.0/food-diary-1.1.0.apk",
  "sha256": "…",
  "size": 31234
}
```

Приложение запрашивает `https://github.com/zigorminsk-debug/eat-control/releases/latest/download/update.json`
(не чаще раза в сутки при запуске и по кнопке «Проверить обновление»), сравнивает
`version_code` с текущей версией и, если есть новая, скачивает APK, сверяет SHA-256
и открывает системный установщик. Если устройство не разрешает установку из этого
приложения, показывается ссылка на соответствующие настройки.

Выпустить новую версию:

```bash
git tag v1.1.0 && git push origin v1.1.0
```

или запустить workflow «Релиз» вручную и указать версию — тогда `versionCode`
автоматически увеличится на единицу.

## Важно о «поиске причин»

Экран анализа показывает совместные записи, а не причинно-следственную связь. Окно 12 часов
и порог 4/10 — технические настройки дневника, а не медицинские стандарты. Приём пищи часто
содержит несколько ингредиентов, симптомы могут зависеть от порции, времени, запора, лекарств
и других обстоятельств. Приложение не ставит диагноз и не заменяет врача. Для более полезных
наблюдений вносите ингредиенты отдельно через запятую, указывайте время и сохраняйте
контрольные записи без симптомов.
